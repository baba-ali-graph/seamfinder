# EdgeDock Privacy Policy

Last updated: 2026-10-05

EdgeDock is a local quick-launch overlay for Android. It does not include ads,
analytics, crash reporting, accounts, or any network access.

## Permissions

| Permission | Purpose |
|---|---|
| Overlay (draw over other apps) | Draws the search bubble and panel over other apps |
| Usage Access | Orders the empty-query list by recently used apps (optional) |
| Notifications | Required by Android so the foreground service hosting the bubble can stay alive |
| Boot completed | Restarts the dock after reboot if you left it enabled |

## Data we store

Only on-device preferences:

- Dock on/off
- Bubble edge position
- List / grid layout preference

EdgeDock never uploads installed-app lists, usage history, or any other
personal data. There is no cloud backend.

## Sharing

We do not sell, share, or transfer personal data to third parties. The app
has no `INTERNET` permission.

## Contact

For privacy questions, contact the developer via the store listing or the
project repository.
